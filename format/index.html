移动收藏

随手格式化，按场景收藏。

  1. 粘贴 JSON 或 XML，选择格式，点击「格式化」。
  2. 内容包含 &quot; 时，点击「&quot; → "」还原双引号，再格式化。只替换这一种实体，不处理其他实体或反斜杠转义。
  3. 输入与结果区可用右侧 / 底部滚动条浏览，底部「阅读」滑块可跳到文档任意位置。
  4. 点击「保存收藏」，选择文件夹并命名。
  5. 左侧点击收藏即可打开；文件夹旁的 × 可删除整夹并移到回收站，支持恢复。
  6. 点击「导出备份」保存全部收藏和回收站；导入备份会追加，保留已有文档。

收藏保存在当前浏览器。清理浏览器数据、无痕模式、换浏览器或换访问地址，可能使收藏不可见。请定期导出备份。

JSON 支持标准对象、数组、外层 JSON 字符串和多层反斜杠转义；会自动解开外层包装，内部字符串保留原样。JSON 压缩不会改变字符串内容或大整数。XML 保留混合文本、CDATA 和 xml:space；不支持 DTD。单文件上限 5 MB。

离线版：下载后用 Chrome 或 Edge 打开 HTML。本地部署版：启动后访问 http://127.0.0.1:8765，可加入浏览器书签。
