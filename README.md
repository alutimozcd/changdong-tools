# 常用工具

两个纯静态网站：
- `format/`：JSON/XML 格式化、外层转义处理、文件夹收藏与备份。
- `time/`：北京时间与英国、荷兰、比利时、卢森堡、法国、德国时间双向转换。

## GitHub Pages

在 GitHub 创建公开仓库 `changdong-tools`，将本目录内的文件和 format、time 文件夹提交到 main 分支根目录。
Settings → Pages → Source: Deploy from a branch → main → / (root) → Save。
使用 Pages 页面返回的实际访问地址，通常为 https://你的用户名.github.io/changdong-tools/ 。
首页、format/ 和 time/ 可分别加入浏览器书签。

不需要构建命令、npm 或数据库。仅提交网页代码，不要提交你的业务文档、收藏备份、令牌或访问凭据。
收藏不会保存在 GitHub，也不会跨电脑自动同步。更换网址后通过备份迁移。
